# CARISHMA

Website for CARISHMA, a bespoke Indian ethnic menswear label in New Delhi by designer Ambika Khanna. A two-page showcase of the studio's wedding catalogue with a WhatsApp enquiry flow, built in plain HTML, CSS and JavaScript.

Live site: https://mobster123.github.io/carishma/

## Structure

```
index.html        Home: hero, designer, collections, process, Instagram, enquiry form
lookbook.html     The wedding catalogue, 35 pages with a lightbox and PDF download
css/style.css     Single stylesheet, custom properties, one breakpoint at 720px
js/main.js        Mobile menu, reveal on scroll, WhatsApp composer, lightbox, deep links
assets/           Photographs, catalogue pages at three sizes, paper texture, favicon, PDF
```

No build step. Open `index.html` in a browser or serve the folder with any static server.
